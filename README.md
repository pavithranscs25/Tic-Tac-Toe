# Tic Tac Toe

A modern Tic Tac Toe game built with React, JavaScript, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Play

- Choose **Vs. Computer** or **Two Players**.
- In computer mode, select **Easy**, **Medium**, or **Hard**. Hard uses Minimax.
- Select an empty square to make a move.
- Use **New game** to start another round while keeping the scoreboard.
- Use **Restart** to clear the scoreboard and board; confirm when prompted.

## Other commands

```bash
npm run build
npm run preview
```
